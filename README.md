# Deepika Sivakumar - Portfolio

Personal portfolio website (plain HTML, CSS and JavaScript - no frameworks or build step).

## Files
- `index.html` - all page content
- `style.css` - styling and responsive layout
- `main.js` - mobile menu, experience tabs, scroll animations
- `assets/` - headshot

## Deploy on GitHub Pages
1. Create a repository named `Deepika-2004.github.io`.
2. Upload all files in this folder, keeping the `assets` folder.
3. Settings > Pages > Deploy from a branch > `main` / root.
4. Live at https://deepika-2004.github.io

## Editing
Open `index.html` in any text editor and change the text directly.
